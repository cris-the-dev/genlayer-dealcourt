  1. 01Agree up front

    The client escrows GEN with terms, a rubric and deadlines. The provider accepts and delivers a URL.

  2. 02Most deals end here

    The client approves, the review window lapses, or both sides propose the same split. No LLM is involved.

  3. 03Dispute

    Both sides file statements. Validators read the deliverable and evidence, score the rubric and rule a split. One bonded appeal is allowed.
